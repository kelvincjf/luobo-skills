# 萝卜·逻辑写作（luobo-clear-writing）

把零散功能说明写成读者跟得上的文章和图文。先回答“给谁看、要讲清什么”，再选时间、组成、比较或论证顺序，用金字塔原理和MECE检查结构，最后才分镜排版。

## 使用

把本目录放进当前支持SKILL.md的宿主技能目录，保留references。安装入口因宿主而异；本包不自动安装软件或发布文章。调用示例：

> 用萝卜·逻辑写作整理这篇图文。正文讲动机和特点，图片讲具体流程；先检查逻辑，再给分镜。

> 只标出下面提纲的分类重叠、遗漏和跳跃，不改我的文字。

可以独立使用，也可供现有写作、配图、小红书发布流程调用；详见[集成说明](INTEGRATION.md)。无模型、网络或Python依赖。不会保证“永远正确”或自动获得爆款。

## 本轮验证边界

有限的Codex隔离写作回放涵盖流程、比较、系统解释、短句格式和证据不足；实际输出与判定见[回放记录](validation/replays.md)。模型复核不等于真实读者研究，没有理解率或Token节省测量。
