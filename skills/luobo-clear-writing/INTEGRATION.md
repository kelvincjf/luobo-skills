# 接入已有技能

这是共用的逻辑组织子步骤，不是第二套写作引擎。调用宿主能找到的同名技能入口，或将整个目录作为项目内参考；不只复制SKILL.md而漏掉references。

- 写作技能：整篇起稿、结构重写、逻辑审稿时，在拟提纲前调用本技能；保持作者原有风格与事实核查。短句微调和只标问题不升级为全篇重构。
- 图文技能：先确认中心意思与排序理由，再写连续说明和标题链，通过语义检查后转成既有分镜数据；原渲染器、品牌与可编辑交付保持。
- 小红书技能：使用references/xiaohongshu.md的图文分工和内容/视觉两层检查。发布技能只复核当前版本的内容结论、图片顺序和现场定稿；有具体逻辑缺陷交回写作修正，不擅自改用户定稿或自动重发。

集成者可在已有Brief/发布记录中记录主线、覆盖和具体审稿结论，不必每篇额外生成审计文件。字段存在、关键词命中、版面脚本退出0均不能判定内容已讲清楚。
