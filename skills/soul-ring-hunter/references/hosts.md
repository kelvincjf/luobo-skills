# 宿主能力映射

本文件是适配契约，不是兼容认证。

| 需要的能力 | 当前宿主中的映射 |
|---|---|
| 发现 / 读取技能 | 使用实际技能目录或显式读取指定 SKILL.md；分别记录发现和读取 |
| 读取 URL / 本地材料 | 宿主提供的网页、连接器、文件工具；需登录时按现有授权处理 |
| 盘点与指纹 | Python 3 标准库；`skill_ops.py inventory` |
| 背景 | 当前会话＋用户/宿主明确授权的少量本地文件或记忆接口 |
| 候选执行 | 当前代理显式执行，或允许的隔离代理/CLI；如实写调用方式 |
| 文件激活 / 回退 | 同一文件系统内、普通技能目录；`skill_ops.py`，不支持软链接目标 |
| 使用记录 | `followup.py` 追加最小记录；仅覆盖主动登记的调用 |
| 定时 | 宿主原生调度器；没有则到下一次调用再检查 |

Codex：技能使用 `SKILL.md`，可选 `agents/openai.yaml` 用于显示名称和默认提示。实际发现目录与权限取当前环境，公开包不硬编码个人工作区。显式读取通过不代表自然语言触发已经通过。

其他支持技能的代理可以读取同一核心。不要机械替换工具名或带上原宿主专属权限声明。Claude Code、Kimi 及使用 DeepSeek 的具体客户端均需分别实测；模型 API 能请求工具调用不代表客户端具有文件、记忆或调度能力。

每次验收记录：宿主与版本、模型（未知就写 unknown）、OS、Python 版本、可用工具、当前/目标是否同环境、候选指纹、实际用例及证据。当前暂停的模型不调用，也不作为完成条件。
